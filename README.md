# Sobhi

Developer building [Pabbel](https://pabbel.com), a privacy-first suite: Mail, Drive, Vault (end-to-end encrypted) and Office.

## Projects

- [turbodm](https://github.com/xsobhi/turbodm): download manager for Linux and Windows with up to 32 connections, resume and a browser extension. Rust.
- [after-effects-linux](https://github.com/xsobhi/after-effects-linux): installer and Wine patches for running your own Adobe After Effects on Linux.
- [fileflip](https://github.com/xsobhi/fileflip): right-click file converter for Windows (images, video, audio). Rust.
- [hotspot-manager](https://github.com/xsobhi/hotspot-manager): Wi-Fi hotspot manager with per-device speed limits and blocking.
- [accent-colour-skill](https://github.com/xsobhi/accent-colour-skill): agent skill and CLI that finds the missing accent colour in a palette.
- [genshin-7.1-linux-fix](https://github.com/xsobhi/genshin-7.1-linux-fix): fix for the Genshin Impact 7.1 launch crash on Linux with Heroic.
